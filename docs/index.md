# Fly Lab

Zero-setup Colab notebooks on the fruit-fly connectome: from "what is a connectome?" to running,
and critically judging, an in-silico experiment. Built on
[flyconn](https://github.com/moiz-lakkadkutta/flyconn) 0.4.0.

**Level:** intro college / advanced high school; "go further" boxes for grad students.
**You need:** basic Python. Each notebook opens in Colab with one click and loads its data in
seconds.

| # | Notebook | You will learn |
|---|---|---|
| 1 | [Meet the connectome](notebooks/01_meet_the_connectome.ipynb) | neurons, classes and cell types; why transmitters are predictions |
| 2 | [Who talks to whom](notebooks/02_who_talks_to_whom.ipynb) | partners, input fractions, and how a synapse threshold changes the answer |

More notebooks (pathways, signs as guesses, simulated experiments and their controls,
male vs female) are planned.

**Honesty labels.** Transmitters are *predicted* unless measured; every simulation output will
be labelled a *model prediction*; controls are part of every experiment.
